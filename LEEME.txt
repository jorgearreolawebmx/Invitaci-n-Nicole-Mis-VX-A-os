PRIMERA VERSIÓN VISUAL Y FUNCIONAL

1. Abra index.html en un navegador moderno para revisar la invitación.
2. La pantalla inicial muestra el video del sobre pausado.
3. Toque el sello (botón invisible superpuesto) para iniciar el video.
4. Cuando termina la apertura, aparece el contenido de la invitación.
5. La invitación está diseñada en una sola columna para desplazamiento vertical en celular.

ARCHIVOS PRINCIPALES
- index.html: estructura y textos.
- styles.css: diseño, colores y adaptación móvil.
- app.js: apertura por toque, cuenta regresiva y galería ampliable.
- assets/: video, fotografías y recursos gráficos.

GENERADOR DE ENLACES PERSONALIZADOS POR FAMILIA
------------------------------------------------
- Al final de la invitación aparece el acceso discreto “LINK PERSONALIZADO”.
- Contraseña de acceso configurada: 12345.
- Después de ingresar, escribe el nombre de una familia y pulsa “GENERAR LINK”.
- El sistema crea una URL con el parámetro ?familia=NombreDeLaFamilia y permite copiarla.
- Al abrir el enlace, la invitación muestra el saludo personalizado con el nombre de esa familia.
- La página y los enlaces son estáticos: no requiere Google Apps Script, Supabase ni base de datos.
- Si abres la invitación desde su URL publicada (GitHub Pages o dominio HTTPS propio), los enlaces se generan automáticamente con esa dirección.
- Si abres index.html desde file:// en tu computadora, el generador te pedirá la URL HTTPS pública de GitHub Pages. Pégala una vez (por ejemplo, https://usuario.github.io/repositorio/) y se recordará en ese navegador.
- Nunca se debe compartir una dirección file:///C:/... porque solo existe en la computadora donde se abrió el archivo.
- Limitaciones: los enlaces no se guardan en un registro central, no hay panel de listado y las confirmaciones de asistencia siguen enviándose por WhatsApp sin almacenarse en una base de datos.
- Seguridad: la contraseña 12345 está implementada en el JavaScript del navegador. Es una barrera visual básica, no un sistema de autenticación seguro; alguien que inspeccione el código puede encontrarla. No utilizar para información confidencial.
